# OpenShift Sandboxed Containers on AWS

## About

This guide is intended for Red Hat Solution Architects who want to demo OpenShift Sandboxed Containers (Kata Containers) on AWS.

Please complete the prerequisites first. After completing the prerequisites, you can pick either Bare Metal or Peer Pod modes.

> NOTE: Bare Metal is the preferred approach.
